# v1.1.0 · 侧键双配置直达与 Lua 导入优化

本版新增侧键指向两个板载配置的切换方式，并修复较大 Lua 源码导入、转换及宏编辑中的卡顿和容量误报。

- **侧键直达两个配置**：设备设置中选择两个槽位和两个侧键，例如 G4 → 配置 1、G5 → 配置 2。当前目标的按键保持当前配置，另一键切到对应槽位；关闭程序后由鼠标执行。只启用所选两个槽位，其他内容保留；提供解除与恢复原按键、启用状态。至少需要两个可写槽位。见[使用说明](https://github.com/XFEstudio/LogiBoardToolBox/blob/master/docs/PROFILE-SWITCHING.md)。
- **大 Lua 源码**：文件上限 16 MiB，导入、运行、转换、导出统一支持最多 4,194,304 个 UTF-16 字符；编辑器分段显示，全部源码仍参与保存、导出和转换。静态表扩展至 65,536 项。
- **转换可取消**：Lua 静态转换在后台运行；取消后保留原文，不创建部分宏。转换提取确定性动作并保留每个 `Sleep` 延迟，不能把通用 Lua 解释器安装进鼠标。见[兼容范围](https://github.com/XFEstudio/LogiBoardToolBox/blob/master/docs/LUA-SUPPORT.md)。
- **改善板载空间利用**：按指令追踪已有宏引用，复用宏页空隙，并回收被替换宏的独占空间；共享宏、其他配置与 G-SHIFT 层保留。容量不足时显示所需/可用/总字节，原配置不因预检失败而改变。
- **长宏编辑**：时间线分段创建控件，避免一次加载上万个按钮；导航和编辑保留完整步骤。
- **合并已有更新**：Lua 导入/导出和软件执行、软件内左右键录制、PRO 2 / SUPERLIGHT 2 / DEX / G402 识别、传统宏页及 CRC 恢复、完整诊断包导出。

验证覆盖 213 项核心测试、WinUI 控件交互和程序自身后台截图。新增配置直达通过内存 HID++ 传输验证写入、读回、恢复和失败回滚，尚未验证各型号实体侧键的实际切换。新增型号的硬件输出和用户所报 Lua 的原始脚本仍需对应实测；本次未修改正在使用的物理鼠标。

原厂固件的“同键按一次开启、再按一次停止”的板载触发宏仍未实现；本版不会将其写成无法同键关闭的循环。仓库内固件研究仅为离线源码，不包含可刷写固件或安装入口。

下载 `LogiBoardToolBox-v1.1.0-win-x64.zip`，完整解压后运行 `LogiBoardToolBox.exe`。这是包含运行依赖的 Windows x64 便携包；校验值见 `SHA256SUMS.txt`。
