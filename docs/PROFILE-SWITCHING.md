# 侧键直达板载配置

在设备设置中展开“侧键直达板载配置”，分别选择两个不同的目标槽位和两个不同侧键，再点“写入双配置直达”。需要鼠标提供至少两个可写板载槽位；左、右、中键保留。可同时设置 G-SHIFT 层。

例如 G4 指向配置 1，G5 指向配置 4：配置 1 中 G4 不切换，G5 切到 4；配置 4 中 G5 不切换，G4 切回 1。重复按当前配置的直达键保持当前槽位。切换由鼠标现有的上一个/下一个配置指令执行，关闭软件后仍可操作，不需要软件按键监听或宏区空间。

这个兼容方案只启用所选两个槽位，其他槽位的配置内容不删除。配置直达期间，所用按键和槽位启用状态被保护，防止意外丢失切回路径；可正常编辑其他按键、DPI 和可板载的设置。若要启用第三个槽位或重新分配这两个键，先点“解除直达并恢复原设置”。

写入沿用完整备份、扇区读回和失败回滚流程。解除时恢复设置前的按键和槽位启用状态，并保留后续的其他修改。恢复记录保存于本机 `Onboard/profile-switch-links.json`，该文件用于显示语义和解除配置；鼠标执行切换无需此文件。换电脑仍可切换，解除设置则需要原电脑的恢复记录或完整备份。

本功能经过离线 HID++ 传输、写入失败回滚和 WinUI 操作回归；多型号实体按键与固件实际切换尚未实机确认。它不是对五个槽位同时任意直达的支持，也不代表原生同键触发宏已实现。
